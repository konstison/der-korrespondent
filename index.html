    Redaktionelle Verantwortung & Entstehung der Inhalte

    Die Essays werden automatisiert mit Hilfe künstlicher Intelligenz (Google Gemini) auf Basis öffentlich zugänglicher Nachrichtenquellen erstellt und anschließend automatisiert gegen diese Quellen geprüft. Trotz dieser Prüfung können Fehler nicht ausgeschlossen werden. Die verwendeten Quellen sind unter jedem Essay aufgeführt.

    Datenschutz

    Diese Website wird über GitHub Pages statisch bereitgestellt. Beim Aufruf erfasst GitHub Server-Logfiles (u. a. IP-Adresse) im Rahmen der üblichen Hosting-Sicherheit. Wir setzen keine Cookies, keine Analyse- oder Tracking-Werkzeuge ein. Schriften werden lokal ausgeliefert.

    Ihre Einstellungen (Schriftgröße, Abendmodus, Sprache, Ressortauswahl, gelesene Essays) werden ausschließlich lokal in Ihrem Browser gespeichert und nicht an uns übertragen.

    Artikelbilder werden direkt von Wikimedia Commons (Wikimedia Foundation) geladen; dabei wird Ihre IP-Adresse an deren Server übermittelt. Die Vorlesefunktion nutzt die Sprachausgabe Ihres Geräts bzw. Browsers.
